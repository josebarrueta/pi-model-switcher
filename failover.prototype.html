Keep working when a model is rate-limited

Question: can Pi continue the same task after a 429 by trying each available model at most once, without looping when every model is unavailable?

Assumptions: start on Codex, prefer a different provider after a 429, exclude rate-limited models until a new task, and keep the working model after success. Other errors and cancellation stop immediately. Completed tool work is preserved, not replayed. No API calls, credentials, storage, or real tool execution.
